# 已知局限与适用边界

> 这份文档的作用是**让你在使用前就知道哪里会出错**，而不是出错后再来解释。
> 每条都标注了「影响」和「缓解措施」——如果缓解不了，会直接说「无解」。

---

## 一、统计与样本

### 1. 回测样本量小

| 项 | 说明 |
|---|---|
| **现象** | 单一形态的历史样本常见 N=5~15 |
| **影响** | N<10 的结论**不可外推**；分段稳定性检验会大幅波动 |
| **缓解** | 报告强制标注 N；`prob.py` 每个阈值都带 `se`（二项标准误）与 `low_n` 标记 |

实测参考：N=44、p≈50% 时，二项标准误 **7.5pp**、95%CI 约 **35~65%**。
**写「50%」并说明精度，优于写「42–52%」这种假精确的窄区间。**

### 2. 幸存者偏差无解

| 项 | 说明 |
|---|---|
| **现象** | 退市 / 长期停牌标的不在数据源样本内 |
| **影响** | 绝对 IC 与胜率**系统性偏乐观**；只能看因子之间的**相对排序** |
| **缓解** | 数据源层面无解。所有因子结论必须注明「绝对数值不可信，只看相对」 |

### 3. 池子前视偏差（已修，但需注意口径）

| 项 | 说明 |
|---|---|
| **历史问题** | 用「今天的成分股」回测「三年前」，等于提前知道谁会进指数 |
| **现状** | 已用 `--max-px` 做逐时点过滤 |
| **仍需注意** | **不固定股票池的结论一律不可比**。两轮符号相反时，先怀疑池子变了 |

### 4. 分段稳定性

| 项 | 说明 |
|---|---|
| **现象** | 同一形态在不同时间段表现可能完全相反 |
| **实测案例** | 某形态次日上涨率「前半 50.0% → 后半 35.7%」（−14.3pp） |
| **缓解** | 报告强制做时间分段；只报平均值等于用单段极值掩盖风险 |

## 二、数据源

### 5. 免费接口会限流

| 项 | 说明 |
|---|---|
| **现象** | 连续请求会被限流；盘前部分字段整批返回 `'-'` |
| **影响** | 限流期间该维度**没有信息量**，不是「值为 0」 |
| **缓解** | 多源降级链 + `_ok()` 判空；**空数据判失败**，不静默当 0 |

> 关键约定：**取不到 ≠ 是 0**。盘前 `clist` 的 `f2/f3/f62` 返回 `'-'`，
> 若不判空直接换算，会把「取数失败」读成「板块普跌」。

### 6. 资金流是推断值

| 项 | 说明 |
|---|---|
| **现象** | 主力 / 超大单净额按成交单金额分档**推断**，不是真实席位数据 |
| **影响** | **拆单会系统性干扰**（大单拆成小单，会被归到「散单」） |
| **缓解** | 恒等关系断言（主力净额 == 大单 + 超大单）；与新浪口径并列展示、**不交叉相加** |

### 7. 盘中快照会变

| 项 | 说明 |
|---|---|
| **现象** | 价格、资金、量比在盘中持续变化 |
| **影响** | 盘中得出的结论是**取数那一刻的快照** |
| **缓解** | 报告标注「信息截止 HH:MM 盘中」；**结论必须收盘复核** |

### 8. 日 K 线末根日期是运行时变量

| 项 | 说明 |
|---|---|
| **现象** | 同一天内，日 K 末根可能从「不含今日」切到「含今日」，再切回来 |
| **影响** | 含不含今日，MA5 可能差 0.03 以上，足以改变「是否失守」的判定 |
| **缓解** | 统一用 `ds.kline_asof(include_today=...)`，返回 `raw_last` / `has_today` / `warn` |

### 9. 板块级口径 ≠ Σ成分

| 项 | 说明 |
|---|---|
| **现象** | 板块资金净额是板块级统计，不等于成分股净额之和 |
| **影响** | 两者**不可交叉比较**，也不可相加 |
| **缓解** | 只并列展示，并在报告里标出各自口径来源 |

## 三、方法与模型

### 10. 模型未通过检验

| 项 | 说明 |
|---|---|
| **实测结果** | 样本外 AUC **0.508~0.528**；Brier **全 ≥ 常数基线** |
| **结论** | **禁止用于选股**，仅作研究记录 |
| **受控实验** | 特征 42→100，AUC 0.5152→0.5158（**零提升**）→ 「不够多」是错觉，「不够独立」才是真相 |

### 11. 因子已饱和

| 项 | 说明 |
|---|---|
| **实测** | 102 个技术因子四道检验后只剩 5 个；扩到 498 只大池后只剩 `amt` / `trend_r2` 站得住 |
| **符号反转** | `pos250` 在大池中符号反转 → **只能当过滤器，不能当信号** |
| **多重比较** | 必须做 Bonferroni 校正（|t| ≥ 3.45），须单列「未过校正」档 |

### 12. 评级是机械打分

| 项 | 说明 |
|---|---|
| **现象** | 四维（技术 / 资金 / 板块 / 情绪）加总，权重与阈值是**经验设定** |
| **影响** | 未做参数优化，不是券商研报，不能当"目标价"用 |
| **缓解** | 各维基准 = 满分 × 50%（中性）；基准不可挑选，取更不利者 |

### 13. PIT 只管「能不能看到」

| 项 | 说明 |
|---|---|
| **现象** | 用财报**实际公告日**做可见性闸门，消除前视偏差 |
| **影响** | **不处理追溯重述**——公司改了上年数据，历史样本会被污染 |
| **缓解** | 严谨研究须自行核对修订公告 |

### 14. 「不交易」不等于「安全」

| 项 | 说明 |
|---|---|
| **现象** | 凯利 f\* ≤ 0 时输出「不下注」 |
| **影响** | 这是**数学结论**（期望收益 ≤ 0），不是对后市的判断 |
| **注意** | 不交易只避免了下行暴露，**不产生收益**；且空仓也有机会成本 |

## 四、小资金的特殊约束

这条不在 14 条里，但实践中最容易撞上：

```
账户权益 × 半凯利 8% ≈ 一手成本上限
```

若账户规模较小，**凯利给出的仓位可能低于一手的最小交易单位**：

| 股价 | 一手成本 | 8% 权益能否覆盖（以 5000 元权益为例） |
|---|---|---|
| 3 元 | 300 元 | 400 元 → **可以** |
| 5 元 | 500 元 | 400 元 → **不行** |
| 10 元 | 1000 元 | 400 元 → **不行** |

此时只有两个合法选择：

1. **放弃这只票**（与「凯利 f\*≤0 不下注」同性质，是合法结论）
2. **明确接受超配**，并在风险提示里写清楚「这违反了分散原则，原因是资金规模约束」

**没有第三条。** 把「买不到一手」说成「现金不足」是错误归因——真凶是仓位规则与最小交易单位的冲突。
