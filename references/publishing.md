# 上架到 WorkBuddy 官方技能市场 · 操作手册

> 基于 **2026-11-09** 可查的公开信息整理。平台「收入变现」仍处于内测/规模化开放过渡期，
> **费率、审核口径、退款与结算规则均可能调整，一切以开放平台后台实时说明为准**。
> 本手册只讲流程与自检，不承诺过审、不承诺收益。

---

## 0. 先想清楚：这个技能适合付费吗

| 判断 | 结论 |
|---|---|
| 技术上能否上架 | ✅ 能。包体积 0.33 MB、纯标准库核心链路、SKILL.md 元信息齐全 |
| 审核能否通过 | ⚠️ 中等可能。金融/投资类 + 脚本密集型，会走安全检查与人工复核 |
| 能否赚钱 | ⚠️ 可能性偏低。目标用户窄（A 股个人投资者 ∩ 用 Agent ∩ 只做主板），且**完整版已在 GitHub 以 MIT 免费公开** |
| 更现实的定位 | 作品集 / 获客入口 / 1 元试水验证需求；受访开发者的普遍反馈是「卖 Skill 更多是获客而非直接收入」 |

**结构性矛盾**：付费资产云端加密运行、买家拿不到源码，但完整源码公开可 clone。
付费版必须提供 GitHub 版没有的价值（**免配置、持续维护、云端直调、案例库**），否则付费理由不成立。

## 1. 上架全流程（**顺序不能反**）

| 步 | 动作 | 入口 / 前置 | 常见坑 |
|---|---|---|---|
| 1 | **开发者认证** | `open.workbuddy.cn`，个人或企业实名（个人需人脸核身），不收费 | 开发者信息四项（头像/昵称/简介/联系方式）未填全，发布入口不解锁 |
| 2 | **先做出 1 个审核通过的资产** | 上传**免费**技能或专家 → 提交审核 | ⚠️ **这是硬门槛**：没有过审资产，「收入变现」按钮是灰的，开不了收款账户 |
| 3 | **上传 zip → 审核** | 后台「技能管理」创建技能、上传 ZIP、填简介 | 官方标注 **7 个工作日**，实测有当晚提交次日上午通过；退回原因在后台看 |
| 4 | **开通收款账户** | 审核通过后 → 「收入变现」→ 填个人/企业资料 → 微信扫码签约 | 官方 24h 内返回，实测常十来分钟；无违规记录是前提 |
| 5 | **选付费并发布** | 回到发布流程 → 选付费 → 买断或订阅 → 填价格 → 上架 | 🔴 **首发必须选付费**：免费发布的资产现阶段**不支持转付费**；收费方式发布后不可更改 |
| 6 | **查账 / 提现** | 「收入管理」看交易与结算明细 | 订单产生满 **30 天**后可按页面提示提现至微信 |

> **顺序反了会卡住**：先点「收入变现」发现按钮灰色，通常就是第 2 步没做完。

## 2. 打包（本仓库已自动化）

```bash
python "<包内绝对路径>/scripts/build_package.py"          # 生成 dist/niuma-cloud-v<版本>.zip
python "<包内绝对路径>/scripts/build_package.py" --wrap    # 若后台要求单一顶层目录
```

| 自检项 | 标准 |
|---|---|
| 体积 | 技能包上限 **3 MB**（本包实测 **0.33 MB / 41 条目**） |
| 结构 | `SKILL.md` 在 zip **根目录**；`scripts/` `references/` `examples/` 为子目录 |
| 必填元信息 | `name` / `display_name` / `description` / `version` / `license` 全部齐备 |
| 私有文件 | `config.json` / `account.session` / `_journal/` / `_privacy_terms.txt` / 中间产物**一律不进包** |
| 分层 | 排除 `CHANGELOG.md`、隐私闸门、发布脚本等开发运维内容；生成 `README_CLOUD.md` 说明社区版 vs 云端版 |

**打包前必跑（内容级隐私的权威闸门）**：

```bash
python scripts/check_privacy.py --all        # 工作区全量
python scripts/check_privacy.py --msg <提交信息文件>
python scripts/check_privacy.py --history    # 历史提交信息
```

> ⚠️ `build_package.py` **只做结构检查**，不做内容级敏感词正则 ——
> 实测两轮都会把「盈亏比 1.29」「本金 0.00」这类**方法论参数**误报成泄漏（P56）。
> 内容隐私以 `check_privacy.py --all`（28 条禁词）为准。

## 3. 过审要点（针对本技能）

| 风险 | 应对 |
|---|---|
| **金融/投资类人工复核** | 保留并突出：免责声明、**不给买卖指令**、所有观点带概率、五段式输出、`--anon` 脱敏。SKILL.md frontmatter 的 `description` 已写明「只给概率与客观推演」 |
| **平台安全审核** | 上架前做安全检查与风险评级，可疑转人工复核；运行时**文件系统 / 网络 / 命令三维隔离** |
| 🔴 **网络隔离导致行情接口不可达** | **最大风险**。本工具强依赖东财/腾讯/新浪/巨潮外网。上架前必须验证；若不可达，付费版价值不成立。用 `run.py doctor` 看 `fields_usable` |
| **命令隔离** | 脚本必须**单条命令 + 绝对路径**，不要 `cd xxx && ...`、不要管道/重定向。统一入口 `run.py` 已满足 |
| **可选依赖装不了** | `thsdk` + `pandas` 约 56 MB，云端大概率装不了 → 设 `THS_DISABLE=1`，`ds_ths` 安静降级为 `None`，零噪声零子进程 |
| **首次运行配置** | `config.json` 不进包，需使用者从 `config.example.json` 复制填写；详情页要写清楚 |
| **盘前降级** | 09:30 前行情字段整批为 `'-'`，动态冒烟会如实判失败（P105）—— 这是设计行为，不是故障 |

**上架前环境体检**：

```bash
python "<包内绝对路径>/scripts/run.py" doctor
python "<包内绝对路径>/scripts/run.py" health --quick
python "<包内绝对路径>/scripts/run.py" smoketest --static
```

## 4. 定价与收费方式

| 维度 | 一次性买断 | 按月订阅 |
|---|---|---|
| 适用 | 功能稳定、更新频率低 | 需持续迭代维护（本工具数据源/踩坑库持续更新） |
| 权限 | 付一次长期使用 | 停续即失效 |
| 定价范围 | **1–9999 元**，自主定价 | 同左 |
| 市场参照 | 官方示例 79 元；已有 29 元买断的垂直工具 | 19 元/月的经营类工作台 |
| 试水建议 | 1–10 元验证「有没有人愿意付」 | — |

> 平台服务费**内测期约 1%**（早期扶持价、非永久）+ 微信支付通道费约 0.6% 量级；
> 可结算收入 = 用户付费 − 退款/争议 − 平台服务费 − 支付手续费。
> **7 天无理由退款**（买断与订阅均支持）。

## 5. 常见退回原因自检（提交前逐条过）

- [ ] 目录层级：后台若要求单一顶层目录，用 `--wrap` 重打
- [ ] `SKILL.md` 元信息齐全，中英文显示名与简介已填
- [ ] 引用的脚本 / 模板**都在包里**（别裸传一个文件夹）
- [ ] 包体积 ≤ 3 MB（专家包上限更高，别混用）
- [ ] 无密钥、无 `config.json`、无个人台账
- [ ] 详情页写清**运行条件**（所需域名、Python、可选依赖、首次配置）
- [ ] 产物截图**脱敏**（不要露出账户资金、持仓或真实标的）
- [ ] 原创声明：本人独立原创，无抄袭搬运

## 6. 上架后维护

- 版本更新走 `v1.2.x` 修订位；每次改动同步 CHANGELOG + 三处版本号 + 源↔安装目录 md5。
- 付费资产有维护义务：接口变更、口径修正、踩坑库增补要跟得上。
- 收入与账单在「收入管理」；用户反馈与风险信号会影响平台运行期评级（可能限流 / 暂停 / 下架）。

## 7. 风险清单（写全，避免期待落空）

1. 平台「收入变现」仍处内测，**费率与规则随时可能调整**，早进场吃的是窗口红利、不是铁合同。
2. **GitHub MIT 免费版**持续存在，付费转化受结构性压制。
3. **网络隔离**一旦生效，行情类能力不可用，付费价值需重新评估。
4. 金融/投资类内容的合规口径可能收紧，详情页与免责声明须随平台要求更新。
5. 平台当前流量有限，直接收入不宜作为主要目标。

> 本手册为流程记录，所有输出**不构成任何投资建议或收益承诺**。
