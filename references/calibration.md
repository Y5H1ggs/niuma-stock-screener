# 校准与参数调优规则（calibration.md）

> 本文件是「自升级」的**裁判规则**：什么情况下允许改参数、改到什么程度、什么情况下**必须拒绝改**。
> 没有这套规则，"自升级"会退化成"向最近几笔行情拟合" —— 那是亏损的加速器，不是进化。

---

## 一、三个不可违反的前提

1. **样本不足不许调参。**
   已平仓交易 < 30 笔时，胜率、盈亏比的任何差异都落在噪声内（30 笔样本下，真实胜率 50% 的
   95% 置信区间约为 **32%~68%**）。此时唯一正确的动作是**继续记录并加大样本**，不是"优化参数"。
   > 工具会强制提示：`calibrate.py` 在样本 <10 时直接打印"任何参数调优都不可靠"。

2. **一次只改一个变量。**
   同时改入场条件 + 止损 + 仓位，之后无论结果好坏都**无法归因**。改动必须可分离。

3. **改动必须留痕。**
   每次改动写入 `CHANGELOG.md`，注明：依据哪份校准报告、哪几笔交易、改前值 → 改后值。
   **没有留痕的改动视为未发生**，下次复盘时不得引用。

## 二、参数调优的触发条件与方向

| 参数 | 允许调整的最低证据 | 正确方向 |
|---|---|---|
| `stop_loss_pct`（止损） | **止损执行率 < 80%**，或出现 ≥2 笔"破线后继续深亏"（亏 > 止损幅度 1.5 倍） | **收紧**（如 -4% → -3.5%）。**绝不允许因为"被止损打脸"而放宽** |
| `take_profit_pct`（止盈） | 盈亏比 < 1.0 **且**胜率 > 55% | 说明"赚的太少"，可上调；若胜率 < 45% 且盈亏比 > 1.5，说明是"截断亏损让利润奔跑"型，**不要**为了提升胜率而提前止盈 |
| `max_price`（价格上限） | 分价格区间统计收益，高价区显著为负（样本 ≥10） | 收紧上限 |
| 入场条件（形态/相对强度阈值） | 按信号来源分组的业绩归因显示某一族**连续 10 笔以上**为负 | 收紧该族准入，而非全局收紧 |
| `max_drawdown_pct` / `halt_days` | 真实出现过一次 ≥ 阈值的回撤 | 只允许**收紧**。熔断阈值放宽等于取消了熔断 |
| `risk_per_trade_pct` | 单笔实际亏损多次接近上限 | 收紧（降仓位） |
| 评分权重（report.py 四维） | 预测校准显示某维得分与后续收益**相关性为负**（样本 ≥50） | 下调该维权重的**加分项**，不要整体重构评分公式 |

**允许的方向永远只有"收紧"或"平移"。** 若某个参数被反复放宽，先问：
是不是在用它掩盖"入场条件太差"这个真实问题？

## 三、预测校准怎么读

`calibrate.py` 输出的预测校准表，读法如下：

| 现象 | 含义 | 动作 |
|---|---|---|
| **平均预测 − 实际频率 > +12pp** | 系统性**高估**（过度乐观） | 对 `predict.py` 输出的概率统一**下修**，或下调其权重 |
| **实际频率 − 平均预测 > +12pp** | 系统性**低估**（过度保守） | 可上调；但先确认不是"样本期恰逢强势市况" |
| **Brier > 0.25** | 不如恒定 50% 瞎猜 | **暂停使用该概率**，改回形态统计 |
| **Brier ≤ 0.25** 且样本 ≥ 30 | 提供了真实信息 | 可继续使用，并可纳入评分 |

**必须同时报"样本量"。** 10 条预测的校准曲线毫无意义 —— 单条预测就能让频率跳 10pp。

## 四、止损执行率的读法（本工具的核心校准项）

`calibrate.py stops` 用 K 线**重建**"本应止损"的笔数：

```
应止损笔数 = 买入日之后、卖出日(含)之前，K线最低价 ≤ 止损价 的笔数
漏单 = 应止损但卖出价 > 止损价
```

- **漏单不等于亏钱。** 若卖出价高于止损线，是"纪律未执行、结果更好"——
  这类案例要**单独记录**：它们会持续诱导你放弃止损纪律。
- 真正的危险是**漏单 + 卖价低于止损线**：那部分是止损纪律可以回收的确定性损失。
- 判读门槛：执行率 < 80% → 必须收紧；连续 3 次"该止损未止损且深亏" → 触发**连亏熔断**复核。

## 五、禁止行为清单（红线）

1. ❌ **绝不修改历史台账**（`_journal/trades.json`）。台账是 append-only 的事实底稿，
   发现录错只能**追加一条修正记录**，不能改写原记录。
2. ❌ **绝不用"最近 N 笔表现好"来支持放宽风控**。近期表现是结果，不是证据。
3. ❌ **绝不为了凑出好看的胜率而缩小样本口径**（例如只统计"信号明确的"）。
4. ❌ **绝不在参数改动后删除旧版本的校准报告**。历史报告的对照价值高于当下结论。
5. ❌ **绝不把"回测胜率高"当作实盘概率**。回测不含情绪、滑点、排队失败（涨停买不进）。

## 六、每次自升级的执行顺序（固定流程）

```
① 实盘发生 → python journal.py add / close        （先记事实，别急着解释）
② 有预测 → python journal.py（record_forecast）    （predict.py 输出落台账）
③ 每周末 / 每 5 个交易日 → python calibrate.py all  （结算预测 + 出四张表）
④ 读第四节的门槛 → 判断是否达到"允许调参"的证据强度
⑤ 达到 → 改 config.json 或 references/*，并写 CHANGELOG（改前→改后 + 依据）
⑥ 未达到 → 什么都不改，只在 CHANGELOG 记一条"本期样本不足，维持原参数"
⑦ 同步：源代码目录 → ~/.workbuddy/skills/选股分析牛马工具/（改完必须同步，否则下次用的是旧版）
```

**第 ⑥ 步和第 ⑤ 步一样重要。** 一份只记录"这期不改"的 CHANGELOG，比一份充满
"优化"记录的 CHANGELOG 更可信。

## 七、本项目的诚实边界（写给自己看的）

- 无创业板/科创板权限，样本天然偏向主板低波动票；**任何跨市场外推都不成立**。
- 资金规模约 6,200 元，**最低佣金 5 元/边占主导**：单笔成本约 0.2% 是本项目特有的约束，
  放大资金后所有费用敏感度结论都会变（见 `fees.py`）。
- 回测使用前复权价，**不含涨跌停无法成交、排队失败、盘中临停**等真实约束。
- 所有形态统计的样本区间横跨多段不同市况（含强势段），**换环境适用性下降**。
