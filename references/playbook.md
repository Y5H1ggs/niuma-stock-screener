# 判读铁律 Playbook（资金 / 情绪 / 板块 / 盘口）

> 这些规则来自实盘教训，每条都对应一次真实的判断失误。**分析任何个股时逐条过一遍。**

---

## 铁律 1｜板块内资金接力偏好（最高优先级）

**凡分析个股（尤其题材股 / 强势股 / 涨停后分歧票），必须做同板块当日横向对比：**

1. 拉同板块成分当日**涨幅排名** → 看涨停/大涨的是哪一类票：
   - **连板基因票**（2板+ 的接力票）
   - **低位首板票**（新启动票）
   - **分歧修复票**（昨日炸板今日反包）
2. 判定资金当下在买哪一类。**目标票若不在资金接力的类型里 → 大概率被抛弃。**
3. **脱离板块警示**：板块整体回暖但目标票独立走弱（板块涨它跌、同板块有涨停它阴跌）→ **必须显式标高危**，不得只用"个股形态"解释。
4. 落地输出："板块内排名 x/N" + "资金接力类型"。

> **教训来源**：2026-09-14 汉缆股份 —— 只看竞价抗跌+技术形态，漏看板块资金选择"连板基因（通达股份2板）"而抛弃"首板后分歧票"，导致逆板块阴跌 −2.9%。

**配套必查（相对强度，铁律 1 的量化形式）**：

```
个股涨幅 vs 板块内涨幅中位数（全量成分，非前100名）
```

- 板块极强但个股**跑输中位数** = 资金在这个方向里选了别的票。
- ⚠️ **中位数必须用「全量成分」计算**：`clist?pz=100` 只给前 100 名，**前 100 名的中位数 ≈ 全市场的 90 分位**，会严重高估门槛、制造"跑输"假象。
  - **案例（方法纠错）**：2026-09-16 通信技术 BK1650 共 382 只——
    - 只看前 100 名 → 中位数 **+5.34%**，得出国脉科技 +3.47% "跑输 1.87 个百分点"；
    - **分页取全量 382 只 → 中位数 +2.22%**，国脉 +2.80% 实际略微**领先**，真实排名 151/382（前 40%）。
  - **正确结论**：国脉不是"跑输"，而是**中游位置**（前 40%，非龙头非吊车尾）。**必须分页取全量后再算中位数**，否则会系统性地把所有中游票误判为弱势票。
- 同时把该板块**涨停/准涨停名单**列出来，看资金接力的**类型**（正主线分支 vs 边缘跟风位）。若目标票不在涨停名单且排名在中后段 → 即使形态完美也下调评级。
- 实现：分页取全量成分（`sector_members(bk, pages=8)`）→ 取涨跌幅列表求中位数；再用 `fl(x['f3'])>=9.7` 筛涨停。脚本：`python sector_compare.py <代码>`（已内置属性桶过滤 + 全量中位数）。

## 铁律 2｜情绪温度三指标（决定"今天该不该做接力"）

| 指标 | 健康 | 危险 |
|---|---|---|
| ① 昨日涨停 `BK0815` / 昨日首板 `BK1630` / 昨日连板 `BK0816` 的「板指涨跌 + 主力净额」 | 板指涨 **且** 主力净流入 | **板指涨但主力净流出 = 兑现型上涨**（散户和中小资金抬价，大资金在出）→ 次日接力胜率塌方 |
| ② 连板梯队高度（全市场 2板及以上家数） | 10 只以上 = 情绪活跃 | 仅 2~3 只 = 情绪偏冷，打板胜率塌方 |
| ③ 主线与涨停分布是否错位 | 涨停票集中在**当日主力净额 TOP 板块** | 涨停票扎堆**非主线小板块**（林业/造纸/黄酒/橡胶/医疗…）= 零散轮动，追这类 = 接脱离资金方向的板块 |

- **案例**：2026-09-16 昨日涨停板指 +3.2% 但主力 **−14.37 亿**；昨日首板 +3.39% / 主力 −11.62 亿；连板梯队仅 3 只 → 当日不宜追涨停接力。

## 铁律 3｜托单消耗识别（盘口真假支撑）

**真正的支撑 = 价格横盘 + 主力资金净流入/回正 + 外盘 ≥ 内盘。三者缺一即为伪支撑。**

- **价格横盘 + 主力资金累计加速流出 + 内盘 >> 外盘 = 托单被动消耗，不是支撑。**
  - 价格不跌是因为下方大托单在**被动接抛压**，不是买方主动进攻。托单被吃完前价格是"假稳"，吃完即自由落体。
  - **此时持股应减/清，不应因"价格没跌"而安心。**
- **盘口验证法**：记录同一价位的托单手数随时间变化。挂单被逐笔吃掉且不断补充 = 有人在真出货给托单。
- **案例**：2026-09-16 北京银行 09:53~10:00 价格锁死 5.60~5.61，但主力累计 09:53 −266万 → 09:56 −2666万 → 09:59 −5812万 → −6705万，同期内盘 28.4万 >> 外盘 12.0万 → 托单被动消耗，随后自由落体。

## 铁律 4｜封单强度（判断涨停票能不能排上队）

- 封单金额 = `买1量(手) × 100 × 现价`
- **封单金额 / 当日成交额** 比值：

| 比值 | 含义 |
|---|---|
| >1.5 | 极死板，散户基本排不上 |
| 1.0~1.5 | 封板结实 |
| 0.5~1.0 | 正常 |
| 0.3~0.8 | **尾盘排队首选区间**（有封板意愿 + 有成交机会） |
| <0.3 | 封板偏松，有炸板风险 |

- 封单比 **>1.5 直接排除**（成交概率过低）。

## 铁律 5｜个股上涨原因：行业 vs 地域 vs 概念

**必须同时查「行业板块」「概念板块」「地域板块」，三者驱动不同。**

- **案例**：2026-09-16 福建水泥 600802 涨 +4.0%，但**水泥制造板块主力 −0.05 亿**、建筑材料 −2.13 亿 → 按行业看它没理由涨；真实驱动是 **福建板块 BK0151（100 只全红 / 9 只涨停 / 主力 +31.39 亿）** 的地域题材（省级"十五五"规划 / 两岸融合）。
- **判读要点**：若目标票在**地域板块内排名靠后**（福建水泥 36/100），说明它是地域题材的**中游跟风票**，不是核心；地域题材退潮时这类票最先被抛弃。
- 同一地域题材里的其他票能反推出主线票的真实驱动，避免把"地域共振"误判为"行业共振"。

## 铁律 6｜f100 行业字段不可信

- 东财 clist 的 `f100` 字段**大面积失真**，任何"板块共振"判断都必须用 `slist` 二次校验。
- **离谱案例**：
  - `600103 青山纸业` f100 = "造纸"，实际属于 **光通信模块 / 通信技术 / 5G概念**
  - `002093 国脉科技` f100 = "教育"（实为通信网络技术服务）
  - `002617 露笑科技` f100 = "电力"（实为第三代半导体）
- 后果：会把主线票误判为杂毛票，或把杂毛票误判为主线票。

## 铁律 7｜竞价判读

| 竞价情形 | 处理 |
|---|---|
| 高开 2~6% + 放量（竞价量 ≥ 昨日 8%） | 接力到位 |
| 高开 >7% 或一字板 | 溢价被吃掉，放弃 |
| 平开 / 低开 | 接力失败，放弃 |
| 同板块须有 ≥1 只红盘领涨 | 板块锚，否则降级 |

⚠️ **竞价中途数据不可外推**：09:15~09:20 可撤单段的委买净多 / 撮合价，在 09:20~09:25 不可撤单段常被大单反向摆布。
- **案例**：2026-09-16 北京银行 09:20 读数 5.67（+0.18%，委买净多 2500 手）→ 09:25 终值 **5.64（−0.35%，竞价内盘 10750 > 外盘 3093）**，完全反转。
- **正确做法**：以 **09:25 之后的最终成交价 + 竞价量 + 内外盘** 为准；若要预判须在 09:24 后重拉并做方向对比。

## 铁律 8｜资金强度分级（主力净额够不够格）

**主力净占比 = 主力净额 / 当日成交额**

| 净占比 | 定性 |
|---|---|
| <10% | 温和，**不构成"大资金强力介入"** |
| 10~30% | 中等 |
| 30%+ | 强势介入 |

- **绝对金额大 ≠ 强**：成交额也大时可信度低。
- **看符号稳定性，不看绝对值大小**：近 6 日主力净额符号若频繁 ±2~4 亿跳变 = **游资对倒**，不是趋势资金。
  - 案例：600664 哈药股份 今日主力 +2.85 亿（池内第一），但近 6 日 −2.66 / +2.74 / −2.40 / +0.33 / +2.80 / +0.13 亿 = 对倒。
- 横向比：同一只票的**历史同级日**（如上次涨停日）主力量级，判断本轮是加强还是衰减。

## 铁律 9｜趋势票 vs 反抽票（趋势口径专用）

- **趋势票**：完整多头排列 `MA5>MA10>MA20>MA60` + 现价站上 MA5 + 近 10 日低点逐级抬高（回调不破前低）+ 近 3 日主力负值天数 ≤1。
- **反抽票**：前一日大跌（−2%~−9%）+ 今日涨停 = **反包型首板**，低吸资金主导，持续性弱于连续推升型。
- **伪趋势识别**：现价跌破 MA5 即短线转弱，即使其余均线仍多头也不合格。

## 技术指标口径速查

| 指标 | 口径 |
|---|---|
| BOLL(20,2) | 中轨 MA20，上下轨 ±2σ；**现价贴上/站上上轨 = 短期过热** |
| MACD(12,26,9) | DIF/DEA/柱；零轴上金叉为强 |
| RSI(6,14,24) | `100*ag/(ag+al)`，ag=平均上涨 al=平均下跌（**勿写补数**）；>70 超买 |
| CCI(20) | >100 超买，<−100 超卖 |
| KDJ(9,3,3) / Slow·Fast Stoch | 高位钝化需警惕；Fast %K=0 = 极端超卖 |
| WR(14) | −20 以上超买，−80 以下超卖 |
| MOM(10) | 10 日动量，正值动能向上 |
| KST | 中短期趋势综合 |
| 位置 | `pos60 = (现价−60日最低)/(60日最高−60日最低)×100`；**盘中用 live 价拼入序列** |

**组合判读原则**：趋势指标（均线、MACD）偏多 vs 摆动指标（BOLL 位置、RSI、CCI）超买 → 结论是**"趋势向上但短期已到技术性高位"**，两者不矛盾。
**分时级与日线级指标口径不可混用**（分时超卖只支持日内反抽，不改变日线偏弱结构）。
