# T+1 隔日模式 · 形态回测方法论

> 目的：把"这只票明天会不会涨"从主观感觉，变成**该股自身历史同类形态的统计分布**。
> 结论永远附带样本量，样本 <10 个时必须显式标注"置信度低、不可外推"。

---

## 1. 数据准备

- **源**：腾讯前复权日 K（最稳、无限流）
  ```
  https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sz002093,day,,,800,qfq
  ```
  → `data.<code>.qfqday`，元素 `[date, open, close, high, low, volume]`，volume 单位手。
- 单次可取 **800 根**（约 3 年）。建议至少 500 根，样本不足 300 根时统计意义弱。

---

## 2. 涨停价与形态判定（主板）

```python
lim = round(prev_close * 1.1, 2)     # 主板 10%
触及 = high >= lim - 0.011          # 容差 0.011
封板 = close >= lim - 0.001
炸板 = 触及 and not 封板
```

- 连板 streak：今日涨停 + 前序连续涨跌幅 ≥9.5% 的日数。
- 上影线幅度 = `(high - close) / close × 100%`（衡量冲高回落）。

---

## 3. 回测口径（核心）

| 项 | 定义 |
|---|---|
| 买入 | **信号日收盘价**买入（模拟尾盘介入） |
| 卖出 | 次日分别统计四种情形：**开盘卖 / 收盘卖 / 盘中最高(理想上界) / 盘中最低(最坏下界)** |
| 输出 | **胜率 + 均值 + 中位 + 极值 + 破位概率**（跌破 −3% / 进纪律区的概率） |

### 必须输出的两列（缺一不可）

1. **次日开盘卖胜率** —— 识别 T+1 实际可操作性的关键。
   - 若开盘卖胜率远低于收盘卖胜率（如 **20% vs 60%**）→ 说明**次日大概率低开**，卖点**必须在盘中冲高**，不能开盘卖。
2. **基准对照** —— 任意日买入次日卖出的胜率/均值。
   - 没有基准就无法判断信号是否有超额收益。

---

## 4. 必做：分档切分 + 极端案例单列

**单看胜率不够！** 必须同时给出：

- 按关键参数**分档**统计（如"炸板按回落幅度分档：<3% / 3~5% / >5%"）。
- **逐个列出的历史案例明细**（日期 / 参数 / 次日开收高低）。
- **最接近今日参数的单个历史案例**（这是尾部风险的唯一可见来源）。

> **案例 A（福建水泥）**："创60日新高 + 长上影>3%" N=15 胜率仅 40% / 均值 −1.96%，但真正有价值的是明细里**3 次次日跌停**（2025-11-05 上影 5.2% → 次日 −10.0%；2025-11-17 上影 3.1% → −10.0%），而**今日上影正好 5.2%，与跌停那次完全同档**——尾部风险无法从均值看出。
>
> **案例 B（国脉科技）**：今日形态（上影 6.3%）历史仅 3 例 → 3 例中 2 例次日大涨，但同档上影那次的量比是 12.24x 而今日仅 3.18x → **量能强度只有四分之一，不可简单外推**。

## 5. 常用形态信号库

| 信号名 | 判定 |
|---|---|
| 炸板（触板未封） | 触及 and not 封板 |
| 涨停封板 | close >= 涨停价 − 0.001 |
| 首板 | 今日涨停 and 前一日未涨停 |
| 涨>3%但未触板 | 涨幅 3~9.5% 且 未触板 |
| 完整多头 + 涨≥3% | MA5>MA10>MA20>MA60 且 涨幅≥3% |
| 完整多头 + 放量>2x | 多头 且 量/20日均量 ≥2 |
| 近3日累计涨>8% | 过热信号 |
| 创60日新高 | 今日 close/high 为 60 日最高 |
| 创60日新高 + 长上影>3% | 新高但冲高回落 |
| 低开>2%后收阳 | open < 昨收×0.98 且 close > open |
| 前5日内有涨停 + 今日收阳 | 短期强 + 今日阳线 |

## 6. 统计输出模板（脚本用）

```
形态名称 | N | 次日收盘胜率 | 均值 | 次日开盘卖胜率 | 次日最高均值 | 次日最低均值 | 破-3%概率
基准(任意日) | N | ... | ... | ... | ... | ... | ...
```

**判读要点**：
- **"触板断层"现象**：摸没摸到过涨停，会把次日胜率劈成两半（触板类 60~78% vs 未触板类 52~53%），基准约 51%。
  - 例：触板未封 N=10 → 收盘卖胜率 70% / 均值 +2.32%；涨>3%未触板 N=59 → 仅 53%。
- 样本 <10 → 标注"不可外推"。
- 样本区间若含多段强势市况（如 2024-09~10、2025-03），**换环境后适用性显著下降**，须在输出中声明。

---

## 7. 情景概率转换（回测 → 输出）

把统计结果转成"明日情景 × 概率"表时：

- 🔴 **≥50% 或排序首位的标"高概率"**。
- 概率来源须可追溯（哪个形态、什么样本量）。
- 样本量小 + 当前情绪偏冷时，**实际概率应再下调一档**，并在脚注注明。

**示例（国脉科技 2026-09-16，触板未封形态 N=10）**：

| 情景 | 概率 | 依据 |
|---|---|---|
| 次日低开 | 🔴 ~70~80% | 开盘卖胜率仅 30% |
| 盘中冲高 ≥+2% 给兑现窗口 | 🔴 ~65~70% | 次日最高均 +4.62% |
| 次日收盘为正 | ~60% | 收盘卖胜率 70% |
| 跌破 −3% 进纪律区 | ~30% | 破位概率 30% |
